# Project Atlas: Working Notes

Shared notes for the Atlas redesign of the TaskFlow mobile app. Anyone at Acme can edit this page.

## Goal

Rebuild the TaskFlow mobile home screen so users can see today's tasks, overdue items and team updates in one place. Target release: 15 January 2027.

## Team

- Product: Riya Sharma (owner), Pooja Nair (design)
- Engineering: Meera Iyer (lead), Sameer Khan

## Decisions so far

- Dark mode ships in the first release.
- Offline mode is postponed to the second release.
- We will reuse the existing notification service rather than build a new one.

## Open questions

- Should overdue tasks be grouped by project or by due date?
- Do we show team updates to Free plan users?
